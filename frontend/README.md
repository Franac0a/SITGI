# CIT Formosa — Frontend

Interfaz del Sistema Integral de Inventario, Stock y Trazabilidad Científica.

## Stack

React, TypeScript, Tailwind CSS, Vite.

## Scripts

```bash
npm run dev        # Servidor de desarrollo
npm run build      # Build de producción
npm run typecheck  # Verificación de tipos
npm run lint       # Linter
```

## Configuración

Copiar `.env.example` a `.env` y ajustar `VITE_API_URL` según el backend.

## Rutas

- `/login` — Inicio de sesión
- `/registro` — Solicitud de acceso
